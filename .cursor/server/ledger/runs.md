# 服务起停台账

Agent 自己起或停服务时记在这里。用来回答两件事：**现在谁在跑**、**这个进程是不是我自己起的**。

- 停服务前先查这里。`by=agent` 且 `user_requested=no` 的可以直接停；`user_requested=yes` 或对不上记录的，报组长，不擅杀。
- 起完立刻补一条：服务名、地址、脚本、PID、时间、谁起的、日志路径、显存占用。
- 停了补 `stopped`。进程已经不在盘上的旧条目属于过期记录，注明一句，不要当现在还在跑。
- 端口和模型名的定义不在这里，看 `services/`。
