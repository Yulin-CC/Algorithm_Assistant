# 本机与服务器连接

这是唯一的连接说明。操作或切换服务器时读本文件。

本文件只放**地图**：主机在哪、目录怎么对应、每个服务的启动脚本在哪。**端口、模型名、请求方式不在这里**，看 `.cursor/server/`（索引 `server/README.md`）；程序读的地址在 `server/config/vllm_server.json` 和 `sam.json`。

主机、目录、服务地址都还没确认。没确认的地址不要沿用到别的机器。

Windows 不起 vLLM / SAM。新的服务在第 3 节加一行：启动脚本绝对路径和权重目录。按次脚本也写在第 3 节。服务是否在跑看 `server/ledger/runs.md`。
